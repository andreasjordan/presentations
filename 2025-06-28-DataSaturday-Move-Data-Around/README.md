### Titel

SQL Server loves PowerShell to move data around

### Veranstaltung

Data Saturday 2025, Sankt Augustin

### Abstract

With a little bit of .NET, PowerShell can establish a very simple and powerful connection to database systems such as Microsoft SQL Server, both on-premises and in the cloud. This makes it very easy to transfer data between different databases in different locations and even Excel files.
In this session we will mainly focus on SQL Server, but also briefly discuss other databases such as Oracle or PostgreSQL. The required systems can easily be set up with the help of containers so that everyone can participate directly.
We will first look at the underlying technologies and then build a small data hub together and optimize it step by step.
Almost all PowerShell code is hidden in functions, which I will publish in advance. However, basic knowledge of PowerShell is an advantage.
